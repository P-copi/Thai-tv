# Thai TV Player v2

แอปเล่น M3U และ M3U8 สำหรับโทรศัพท์ แท็บเล็ต และ Android TV

## Features

- M3U playlist
- M3U8/HLS playback
- Android phone and tablet
- Android TV and D-pad remote
- Favorites and history
- Picture-in-Picture
- VLC-inspired dark interface

## Notice

ใช้สำหรับเปิดสตรีมและ Playlist ที่ผู้ใช้มีสิทธิ์เข้าถึงเท่านั้น
